# 域名发布地址页

当前仓库保留了静态发布页与后台原型，同时新增了一套可独立部署的 **Python 安全订阅后端**，用于把用户、订阅、加密内容和远程数据库能力真正落地。

## 当前内容

- `index.html`：前台静态地址页。
- `admin.html`：后台原型页。
- `backend/`：基于 FastAPI + PostgreSQL 的后端样板，支持远程数据库、安全认证、订阅管理、加密内容存储与审计日志。

## 新增后端能力

- 远程 PostgreSQL 数据库连接配置。
- 用户注册、登录、JWT 鉴权。
- 套餐、订阅、加密内容接口。
- 订阅内容按需解密，避免数据库中明文保存。
- 登录限流、Trusted Hosts、CORS、安全响应头、审计日志。
